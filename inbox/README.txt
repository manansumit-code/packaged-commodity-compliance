DROP YOUR PHOTOS IN THIS FOLDER.

Photograph the pack with the printed calibration card lying flat
against the same face as the printing. Copy those photos in here.

Then, in a terminal, from the project folder, run:

    ./scan

Every photo in this folder is scanned and the result is printed in
plain English. The photo and its result then move into "done", so this
folder always shows what is still waiting to be scanned.
